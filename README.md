# Аксон IELTS

Личная платформа подготовки к **IELTS General Training (цель 6.5)** с медицинским треком под **USMLE**.

## Что внутри

| Раздел | Объём |
| --- | --- |
| Грамматика A1–C1 | 77 тем, 390 упражнений (из них 9 тем — язык медицины и USMLE) |
| Лексика | 280 тем, ~7000 записей (общая — 237 тем, ~5000 уникальных слов: A1 ~720, A2 ~1320, B1 ~1720, B2 ~930, C1 ~270) |
| Медицинская лексика | 43 темы, ~1020 терминов: базовая, USMLE Step 1, USMLE Step 2 CK, язык вопросов USMLE |
| Listening | тексты с озвучкой, вопросы, диктант, пересказ |
| Reading | задания GT в формате True/False/Not Given и пропуски |
| Writing | 12 писем (Task 1) и 15 эссе (Task 2) с проверкой ИИ |
| Speaking | 15 тем Part 1, 16 карточек Part 2 + Part 3, разговор с ИИ, 8 медицинских ролевых игр |
| Тесты как в Quizlet | карточки, заучивание (выбор → написание), смешанный тест с оценкой, подбор пар на время — для любых тем лексики и грамматики |
| Прочее | входной тест, интервальное повторение (SM-2), тетрадь ошибок, прогресс, видео YouTube к каждой теме |

## Структура

```
index.html          — готовая платформа (один файл)
build.py            — собирает index.html из src/
src/template.html   — разметка и стили
src/content/        — контент: g*.js грамматика, v*.js лексика, u*.js USMLE, m*.js тесты/Speaking/Writing/Reading
src/app/            — логика приложения
```

Добавить слова или тему: отредактировать файл в `src/content/`, затем `python3 build.py`.

## ИИ-функции

Проверка эссе, распознавание речи, озвучка, генерация упражнений и ролевые игры работают, когда платформа открыта как артефакт в Claude. При открытии `index.html` напрямую или на GitHub Pages работает весь встроенный контент, а ИИ-кнопки показывают уведомление.
